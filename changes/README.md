# Changes

Each pull request that changes what users notice adds one file here.

Name it `changes/<issue>-<slug>.md` where `<issue>` is the issue number.

Line 1 is the section: Added, Changed, Deprecated, Removed, Fixed, Security or Internal.
Line 2 is blank. From line 3 is the entry text.

Example:

```md
Fixed

Correct handling of empty email addresses on login.
```
